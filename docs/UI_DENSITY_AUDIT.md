# MEDIPICK UI 밀도 감사 (2026-10-29)

강남언니·바비톡류 병원 탐색 앱 대비 시안 개선 메모.

## 발견 이슈

| 구역 | 문제 | 조치 |
|------|------|------|
| 히어로 | `min-height:540px` + 좌측 패딩 59px → 첫 화면 대부분이 빈 공간 | `layout-refine.css`로 패딩·min-height 제거, 검색 박스 우선 |
| 히어로 비주얼 | 절대배치 475px 아치 + halo → 레이아웃 깨짐·여백 과다 | 상대 배치·halo 제거, 신규 `hero-home.jpg` |
| 헤더 | B2B 링크 2개 + 긴 GNB → 소비자 시선 분산 | `header-ops`는 와이드에서만, `입점 문의` 단일 CTA |
| IA | 빈 지도(400px)가 카테고리보다 위 | 순서: 트러스트 → 진료과 → 스폰서 → 내 주변 |
| 진료과 | 6열 그리드 + 카드 140px → 모바일 밀도 불균형 | 가로 스크롤 원형 썸네일 PICK |
| 섹션 | `padding:74px` 반복 → 스크롤 피로 | 52px(모바일 32~40px) |
| 지식 배너 | CSS 일러스트만 → 마케팅 무게 약함 | `knowledge-visual.jpg` 배너 아트 |
| 카피 | 트러스트바 "강남언니형" 노출 | 중립 카피로 교체 |
