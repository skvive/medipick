# MEDIPICK v1.0 · 제품 설계 및 상세페이지 기준

## 비전

국내 병원·약국 디렉터리 기능에 **선택권을 보장하는 의료지식 콘텐츠 허브**와 **입점 광고 비즈니스**를 결합한다. 오퍼레이터가 승인한 자료를 우선 노출하되 공공데이터·의사 작성 콘텐츠·유료광고를 데이터/화면에서 엄격히 구별한다.

## 사용자 여정

1. **탐색:** 홈 → 진료과 선택 또는 자연어 입력 → 검색 결과. 광고는 관련 카테고리 최상단이나 반드시 `유료광고` 라벨.
2. **정보 검증:** 의료기관 상세 → 공식 연락처·주소·출처 → 의료진 자격 검증 상태 → 전문의/학회 소속 → 의사 블로그·쇼츠·영상 원문 → 근거 링크.
3. **선택:** 방문 편의 후기/의료기관 공식 사이트/전화/예약 요청. 치료후기·효능 단정 금지.
4. **예약:** 개인정보 최소 입력 및 동의 → 요청 접수 ID → 운영자 승인 → 달력 내보내기 → 공급사 알림 연동(별도 승인).
5. **운영:** 관리자 → 기관/의료진/CMS 데이터 검수 → 광고 캠페인 승인 → 예약 처리 → GA4 및 내부 이벤트 성과 확인.

## 운영자 편집권과 광고 우선순위

- `providers.verified` = 기관 정보의 운영자 검증 표시, 의료 품질 순위가 아님.
- `doctors.verification` = 의사 자격 검증 상태, 협회/학회 membership 자동 인정이 아님.
- `content.approved` = 편집자 승인 여부. `content.editorial_priority`는 승인 콘텐츠 편집 우선순위.
- `ads.priority`는 관련 카테고리 **유료노출 선배치** 순위. `ads.approved=1` 필수.
- 검색 결과의 광고/편집자료/공공 데이터는 화면에 각각 라벨. `verified`는 광고에 의해 변하지 않음.
- 광고 고객은 `/advertiser`에서 기관별 30일 조회키로 성과 지표를 **집계값만** 확인할 수 있음. 상담 신청자 개인정보는 광고주에게 일괄 노출하지 않음. 키는 서버에 SHA-256 해시로 저장하고 관리자가 폐기 가능.

## 의학 콘텐츠 필드와 편집 체크리스트

필드: `doctor_id`, `provider_id`, `title`, `summary`, `kind=blog|shorts|video|guide|paper`, `category`, `url`, `evidence_url`, `author_label`, `approved`, `editorial_priority`.

**단계별 검수:**

1. 작성자·의사면허·전문의 자격·소속기관 관계 확인.
2. 학회에 실제 소속되어 있는지 검증; 일반 진료과 정보와 전문의 자격 구별.
3. 의학정보 작성/수정 시점, 원문 링크, 인용 자료·저작권 상태 확인.
4. 이득과 부작용·한계 모두 기술됐는지 확인. 치료성공률·과장·우월성 표현 금지.
5. 광고성 콘텐츠인지, 협찬/비용 수수 관계인지 표시, 법적 심의 필요 여부 판단.
6. 폐기·정정·원문 삭제 시 웹사이트 링크/표시 동기화; 모니터링과 재검수 주기 마련.

**콘텐츠 디테일페이지 확장 기준(후속 단계):** 질환/상황 개요 → 의료진 설명/블로그 원문 → 설명 영상/쇼츠 → 선택 전 체크리스트 → 치료방식의 일반적 이득·위험 → 공개 근거/가이드라인 → 등록된 의료기관 연결 → 상담·예약. 의료 관련 개인화는 추천이 아닌 정보 탐색 지원으로 분리한다.

## 광고 상품과 매출 지속성

| 상품 | 운영 개념 | 지표 | 준법 확인 |
|---|---|---|---|
| 카테고리 스폰서 | 카테고리별 선배치 고정 패키지 | 노출, 클릭, 상세 조회 | 광고 주체/문구/사전심의 |
| 지역 프리미엄 | 서울/부산 등 지역별 후원 슬롯 | 검색, 지역별 CTR | 업종·지역 일치 |
| 의사 콘텐츠 스튜디오 | 승인된 블로그·쇼츠 CMS 이용료 | 원문 유입, 콘텐츠 열람 | 광고와 편집정보 구별 |
| 광고 보고서 | 월간 성과 대시보드/CSV | CTR, 예약요청률 | 환자 데이터 배제 |

광고주 포털은 **수익 정산·결제가 아니라 지표 열람**만 구현됨. 실계약, 청구서, 정산, 사전심의 검증은 별도 연동이 필요함.

의료법 적합성을 검토하기 전에는 상품 가격이나 ‘1위 병원’ 등 허위 성과 표현을 사이트에 게시하지 않는다.

## 실제 상용화의 선행 과제

P0: 법률/의료광고 검토, 개인정보보호 영향평가, 동의 및 운영약관, 상용 서버/DB, HTTPS, 관리자 권한·MFA, 네트워크/디스크 암호화, 자동 파기.

P1: 전국 의료기관 최신 원천데이터 대량 수집/동기화, 유료/무료 기관 검증 체계, 전문의 명단/면허/학회 소속 검증, 심야영업 출처와 갱신주기, 저작권/콘텐츠 원문 연동 승인.

P2: 병원별 예약 가능 시간 동기화, 동시성/중복예약 제어, 카카오 알림톡 계약, SMS 벤더 실제 발송 콜백, Google Calendar OAuth, GA4 설치/실측, 지역화 및 광고주의 계약·결제.

P3: 생성형 AI RAG(검색인덱스+버전관리+인용 검증+AI 결과 검수), 이용자 맞춤형 범위 내 의료정보 가이드, 부정광고/부정후기 자동 탐지, 접근성 WCAG 및 고부하 테스트.
