## 1. 브랜드 포지셔닝과 문구

브랜드 약속: **병원 선택 전에, 의사의 지식부터.**

영문: **Know the doctor before choosing a clinic.**

보조 메시지: “읽고, 이해하고, 내 가까운 의료기관까지.” / “의사 블로그·쇼츠·객관적 출처를 한눈에.”

정체성: 치료를 권유하거나 환자의 질병을 진단하는 서비스가 아니라, **의료정보 출처·의료진 검증 상태·기관 방문 편의·유료 광고를 구별해 보여주는 탐색 플랫폼**. 고객은 병원과 의사, 운영자, 일반 이용자이며 의학적 판단은 적격 의료인이 합니다.

## 3. 소비자 획득 — 콘텐츠 유입 퍼널

**탐색형 랜딩**: `[증상/관심사 관련 일반정보] → [검수한 의사 원문] → [진료과별 확인 체크리스트] → [유료 구독병원 목록(광고)] → [병원 상세보기] → [전화/예약 요청]`.

증상 검색을 자동 진단/치료 추천으로 오인시키지 않습니다. 응급증상 예시는 119로 안내. 콘텐츠의 의학적 근거가 부족하면 추측하지 않고 출처 부족을 표시합니다.

- 피부과: 여드름·피부장벽·자외선 등 공신력 있는 일반지식과 진료과 선택 정보.
- 정형외과: 목·허리·무릎 통증에 대한 일반 의료정보와 언제 진료받을지 확인할 사항.
- 성형외과: 진료 전 상담에서 확인할 사항, 수술 위험성·회복 과정의 일반적 안내(효과 보장 불가).
- 내과: 검진 항목과 이해 방법, 만성질환 관련 객관 자료.
- 치과: 정기검진, 구강관리, 진료과별 설명.
- 소아청소년과/산부인과/안과/이비인후과/정신건강의학과: 연령별·진료과별 정보 원문 정리.
- 약국: 공식 심야약국 안내, 실제 영업시간 재확인 경고.

### 3-1. SEO 랜딩 클러스터

`/specialty/dermatology/seoul/gangnam` 같은 **콘텐츠 있는 지역·진료과 페이지**를 중장기적으로 개발(현 MVP에는 URL 라우팅 미구현). 한 페이지에 `진료과 개요 / 작성자 검증 / 공식 데이터 기준일 / 의료기관 카드(광고 명시) / 원문 출처 / FAQ`를 배치. 기관·의료진·의학 자료에 각기 정형 메타정보 및 `LocalBusiness`, `Person`, `Article`, `VideoObject`를 실제 확인된 속성만으로 적용. 메타데이터는 구글 상위노출을 보장하지 않습니다.

### 3-2. 소셜 분배

의사는 본인 Blogger에 글 게시 → 메디픽 검수 후 유입 인덱스 생성 → 짧은 영상과 설명 본문 상호 연결 → 영상 설명란에 **의사 소유 원문 URL**과 메디픽 기관 프로필 링크. 무단 원문 전재 금지. 광고성 콘텐츠는 소비자에게 광고임을 명시하고 관련 고지 의무 검토. 제휴 의사에게 “30초 의학 Q&A”, “수술 전 5가지 질문”, “검진 결과 용어 해설” 등의 주제 템플릿 제공하되, 의사가 직접 내용 검수 및 승인하도록 운영.

## 4. 병원/의사 입점과 Google Blogger 네트워크

### 추천하는 입점 여정

1. 기관 프로필 등록(공공데이터에 없는 정보는 병원 직접 확인).
2. 의료진의 소속·전문의 자격·학회 소속에 대한 문서 검증. **학회 회원 = 전문의 자격이 아님**.
3. 본인 Blogger **공개 주소** 등록. OTP를 Blogger 공개 글에 넣어 도메인 소유권 확인.
4. 편집자 승인 후 **게시물 제목·요약·원문 링크** 수집. 중복 URL 차단, 승인 전 비공개.
5. 진료과·지역·질문 키워드별 관련 콘텐츠 묶음 노출.
6. 광고 상품 구독(결제 확인, 법률심사, 만료 관리)과 의학정보 발행 권한 **별도 계약/상태**.

현재 v2에서는 공개 `*.blogspot.com` URL을 대상으로 코드 검증+수동 승인+수집 대기를 구현. **Google 계정 OAuth 로그인이나 자동 소유권 진위 추적은 미구현**. 타인의 블로그를 사칭한 연결이 발생하지 않도록 상용 운영에서 기관 담당자 신원 검증, 이메일 확인, 관리자 계정 분리, 감사기록, 사전 검수 및 취소 절차를 추가해야 합니다.

### 마케팅 실험안

| 실험 | 대상/가설 | 측정 | 통과 기준(제안) |
|---|---|---|---|
| A | 병원 가입 랜딩 A/B: “의사 지식 허브” vs “지역 광고” | 등록 완료율 | 상대 개선 20% 이상 | 
| B | 의료진 블로그 코드 등록 안내문 간소화 | 코드 검증 성공률 | 60% 이상 목표 | 
| C | 의사 블로그/쇼츠 연결 프로필 | 원문 클릭률 | 5% 이상 목표 | 
| D | 진료과 스폰서 카피 명확화 | 광고 클릭→기관 상세보기 | 캠페인별 재계약 판단 | 
| E | 지역 기반 구독 병원 탐색 | 위치 동의율·결과 클릭률 | 접근성/기대치 충족 확인 | 

모든 수치는 **사전 설정 가설**이며 검증된 산업 벤치마크가 아닙니다.

## 5. 광고 수익을 지속가능하게 하는 상품 설계

수익 우선순위 = `적법성/승인` > `해당 카테고리 관련성` > `유효 결제 구독` > `광고 편성 우선순위`. **임상 품질·의사 실력·치료 성과를 광고비로 조정하지 않음.**

- 기본 등록: 공식 공개 의료기관·약국 디렉터리 검색 대상. 누구든 객관 정보를 확인할 수 있도록 별도 탐색 모드 유지.
- Starter(가정): ₩199,000/월. 의료기관 프로필, 블로그/쇼츠 연결 요청, 집계 대시보드.
- Growth(가정): ₩499,000/월. 지역+진료과 **스폰서 영역**과 **내 주변 유효 구독병원 지도** 등록(준법 승인 필수).
- Premium/Enterprise: 타깃 지역·병원 체인별 협의. 광고심사·사업자 확인이 선행되어야 함.
- KPI는 광고노출, 상세조회, 전화 클릭, 예약 **요청** 수, 원문 클릭. 병원 방문/실예약 확정 수는 검증 없이 주장 금지.
- 광고주에게 환자 성명, 전화번호, 건강 질의, 예약 메모, 개인 위치를 전달하지 않음. 최소 집계만 공유.

**리스크:** 유료광고만 보이는 지도는 사용자가 전체 의료기관 목록으로 오해할 수 있어 “유료 구독기관만 표시”를 상단과 빈 결과에 반복 안내. 비가입 병원이 없는 것처럼 표현하거나, 검증되지 않은 가상 평가점수를 붙여서는 안 됩니다.

## 6. 디자인 시스템

- 색: 딥 메디컬 그린 `#126a5b`, 배경 민트 `#e6f4ed`, 본문 `#24312f`, 보조 CTA 오렌지 `#ff8767`.
- 사진: 12종 AI 생성 실사형 **진료과 예시 이미지**, 특정 실제 의사·기관의 모습이 아님. 사진에 “AI 생성 연출 이미지” 명시. 상용 병원 공식 사진은 권리 확인 후 교체.
- 서체: Noto Sans KR/시스템 고딕, 모바일 최소 14px 본문 권장.
- 사용자 탐색 3요소: 진료과 이미지 카드 → 질문 기반 검색 → 광고 여부 명시한 기관 비교.
- 정보는 진료과 → 의사 자격 확인 → 콘텐츠 원문 → 기관 상세 → 예약요청 순서로 단순화.
- 지도는 Google Maps SDK가 연결된 경우에만 Google 지도로 표기하고, SDK 키 없는 경우 목록만 제공.
- 운영자 표면은 기관·광고·블로그 검수·광고 만료·지도 장소매칭을 한 흐름으로 묶음.

## 8. 투자자에게 공개해야 할 사실

- 현재 **가상 데모 병원·의료진**과 **AI 생성 연출 사진**을 활용한 작동 가능한 MVP.
- 실제 유료 구독자, 실매출, 예약 확정, 의학적 임상 효과, 실제 Google 지도 API 성공은 입증되지 않음.
- 14장 한/영 투자제안서에 표기한 가격·기관 수·투자 요청 금액은 **예시·제안**이며 매출 예측 확정이 아님.
- Google Maps API 키와 결제, 전문의 검증, Blogger 실계정, 카카오/문자 실제 발송, 개인정보/의료광고 법률 검토는 후속 과제.

**핵심 투자 논지:** 의료진이 직접 발행한 설명을 투명하게 연결할수록 이용자 탐색이 풍부해지고, 유료 광고주는 정당한 표시 하에 진료과·지역 수요와 연결됩니다. 광고 선배치만으로 의료 신뢰성을 약속하지 않고, 실제 전환 데이터와 재계약 지표가 확보될 때 사업을 확장합니다.
