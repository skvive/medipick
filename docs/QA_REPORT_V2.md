## 실제 UI HTML/CSS/JS 브라우저 스냅샷 검수

`qa_visual_offline.py`는 Chromium에서 **실제 앱 HTML/CSS/JS**를 로딩하되, 브라우저 자체가 외부 사이트/localhost 네비게이션을 허용하지 않는 환경 제약상 HTTP API 응답을 서버 기능에서 얻은 **고정 스냅샷으로 주입**합니다. 따라서 **완전한 브라우저-서버 실네트워크 E2E가 아님**을 명확히 구분합니다.

- 데스크톱: 사진 카테고리 **12개**, 스폰서 병원 카드 3개, 가로 넘침 0px, 내 주변 유료 구독 병원 4개, AI 스폰서 카드 1개.
- 모바일: 카테고리 12개, 광고 카드 3개, 가로 넘침 0px, 내 주변 유료 구독 병원 4개.
- 화면 실행 JavaScript 오류: **0건**.
- 실제 Google 지도 API 브라우저 키가 제공되지 않아 **SDK 마커/Places 응답/결제 연결은 미검증**.
- 실제 공개 Blogger 블로그 검증코드 게시/소유권 및 Google/OAuth 로그인은 **실계정 환경에서 미검증**.
- 카카오 알림톡·문자 실발송·병원 실예약 확정은 **미검증**.

## 투자제안서 PDF 문서 검수

- 한국어/영어 각각 14페이지 PDF 생성, PDF 메타정보로 페이지 수 확인.
- 표지·재무 시나리오·영문 마지막 페이지 PDF 렌더링 시각 검수.
- 통계 출처는 NHIS 2026년 2분기, DataReportal, Google Search/Maps/Blogger 공식 문서.
- 가격·가정 MRR·투자 요청 규모는 실제 매출/계약으로 주장하지 않도록 본문 내 주석 표시.
